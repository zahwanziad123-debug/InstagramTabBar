# Instagram Tab Bar for Android

Native Android recreation of a floating, minimizable five-tab navigation bar using Kotlin and Jetpack Compose.

## Build APK
A GitHub Actions workflow builds a debug APK on every push. Open the **Actions** tab, select the latest `Android APK` run, and download the `InstagramTabBar-debug-apk` artifact.

## Build locally
Open this repository in Android Studio, sync Gradle, then choose **Build → Build APK(s)**.

This is an Android recreation of the interaction, not Apple's SwiftUI implementation or a pixel-perfect copy of Instagram's proprietary icons.
